**Founder:** Andy Kloak (Solo founder, London)
**Company:** Data Fetcher (Airtable extension)
**Revenue:** $23K/month ($276K annual), 600+ paying customers
**Model:** Platform add-on (similar to Cintosheets)
**Background:** Freelance React developer → TikTok directory → Data Fetcher
**Strategy:** Platform cloning + validation framework

## 2. The Seed - Idea Came From Friction

**While Building Newsletter:**
- Pulling financial data into Airtable manually
- Thought: "This is tedious"
- Realized: "There should be an integration for this"

**The Insight:**
Google Sheets had "API Connector" add-on doing this well (100K users)
Airtable was growing fast
Same pattern should work for Airtable

---

## 3. The Opportunity - Platform Strategy

**Key Realization:**
"I saw a very similar add on for Google Sheets called API Connector and they were doing super well. They had like 100,000 users and seemed to be like smashing it."

**The Framework:**
1. Find growing platform (Airtable was at inflection)
2. Find proven problem (API Connector proved it)
3. Build similar solution on new platform
4. Capture early market share

**Why It Works:**
- Platform growth = automatic TAM expansion
- Proof of concept on other platform = de-risks
- Early to marketplace = competitive advantage

---

## 4. The Product - Data Fetcher

**What It Does:**
Connects any external platform to Airtable via API
Automatically pulls data in (instead of manual copy-paste)

**Use Cases:**
- Marketing data (Facebook Ads, Google Analytics → Airtable)
- Operations workflows (QuickBooks data → Airtable)
- Financial data (APIs → Airtable dashboards)
- And many more (Andy is surprised by creativity)

**Why It's Valuable:**
- Airtable is powerful but data is scattered elsewhere
- Manual data entry is tedious
- APIs exist but connecting them is technical
- Data Fetcher solves the bridge

## 7. The Platform Opportunity Framework

**Andy's 6-Step Framework for Finding Platform Opportunities:**

**Step 1: Find Growing Platform**
- Tool: Exploding Topics (identifies breakout platforms)
- Look for: Rapid user growth, ecosystem potential
- Examples: Airtable, Zapier, Figma, Webflow

**Step 2: Find Pain Point**
- Source: Forums, Reddit, Twitter, support channels
- Question: What are users struggling with?
- Evidence: Multiple people asking same question

**Step 3: Borrow Proven Pattern**
- Look at: More established platforms (Google Sheets, Figma)
- Find: Similar add-ons/extensions that work
- Copy: UX patterns + business model

**Step 4: Check Integration Capability**
- Research: Does platform have public API?
- Verify: Is there marketplace/SDK?
- Confirm: Can you actually build this?

**Step 5: Napkin Math**
- Estimate: Platform user count
- Assess: Problem frequency (% who have this pain)
- Project: Willingness to pay (compare to established platform)
- Result: Addressable market size

**Step 6: Platform Risk Assessment**
- Question: Will platform build this feature?
- Research: What's on their roadmap?
- Analyze: How likely is feature parity?
- Decide: Is this defensible long-term?

---

## 8. Platform Risk

**The Biggest Challenge:**
"The main downside is the platform risk. So like your tool becoming kind of redundant overnight."

**For Data Fetcher:**
- Airtable could build native API connector
- That would eliminate need for Data Fetcher
- But: Andy feels safe because:
  - Airtable has scripting (advanced users)
  - Airtable has no-code imports (basic users)
  - Data Fetcher fills middle ground
  - Unlikely Airtable builds something "in between"

**The Safety:**
"I think it's safe for now, Touchwood."

But always a risk. This is the tradeoff of platform-based businesses.

## 9. Why This Strategy Works

- Platform recommends you
- No CAC (marketplace does marketing)

**Timing:** Growing platforms create expanding TAM

- Reduces launch risk

## 12. Lessons for Founders

**Lesson 1: Copy Then Improve**
Don't try to innovate entirely new category. Copy working model from bigger platform, improve for new platform.

**Lesson 2: Validate Before Building**
Forums, Reddit, and support channels show real demand before you code.

**Lesson 3: Platform Growth Compounds Revenue**
You don't grow revenue, platform grows for you.

**Lesson 4: Sustainable Beats Explosive**
$23K/month solo > $0 waiting for venture funding.

**Lesson 5: Document the Framework**
Andy's 6-step framework is replicable by anyone. Find other platforms, repeat process.
