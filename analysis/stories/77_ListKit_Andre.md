# Story Index: Andre Heckel - ListKit ($2.4M SaaS in 87 Days, Productized Services Framework)

**Founder:** Andre Heckel (Designer turned productizer)
**Company:** ListKit (Email list building SaaS)
**Achievement:** $2.4M ARR in just 87 days
**Model:** Productized service → SaaS transition
**Speed:** 5 weeks design, 2 weeks beta, 2 weeks launch to $200K MRR
**Strategy:** Solve your own problem + move fast

---

## 1. The Pre-ListKit Journey

**Designer Life:**
- Freelance designer for 3-4 years
- Mostly Shopify store design
- Good income but plateaued

**Why Services Suck:**
- Time for money trap
- Can't scale (only 24 hours)
- Feast/famine cycles
- Client management overhead

**Epiphany:**
- Realizing: Design expertise = commodity
- Noticing: Boring design tool clients = actual problem
- Opportunity: Build tool for designers + entrepreneurs

---

## 2. The Pre-Product Research

**The Problem Identified:**
- Clients constantly asked: "Can you help me build my email list?"
- Recurring request = validation
- Opportunity: Build tool to do this

**Initial Approach:**
- Started as service: "I'll build your email list"
- Did it as service for 5-6 clients
- Charged $1K-$3K per client
- Worked, but time-intensive

**Realization:**
- Why not build software to do this?
- Productize the service = scale
- Keep margins = huge

---

## 3. The Build - Speed Over Perfection

**Timeline: 9 Weeks Total**

**Week 1-5: Design (5 weeks)**
- Not building yet
- Designing entire product
- Building Figma mockups
- Getting customer feedback on mockups

**Why Mockups First:**
- Fast feedback loops
- Customers validate direction before dev
- Kill bad ideas early
- 10x cheaper than building wrong thing

**Customer Feedback Approach:**
- Showed Figma mockups to 5-6 future customers
- Got reactions: "Yes, I'd pay for this"
- Knew had product-market fit before writing code

**Week 6-7: Build (2 weeks)**
- Actual development phase
- Focused on MVP core features
- Not perfection
- Ready to launch

**Week 8: Beta (1 week)**
- Limited beta customers
- Real feedback
- Tweaks based on actual usage
- Not the cleanup phase

**Week 9: Launch**
- Went live to public
- Prices: $29/mo basic, $99/mo pro
- First month: $200K MRR ($2.4M ARR run rate)

**Results After 87 Days:**
- $2.4M annual run rate
- 600+ customers by day 87
- Profitability: Immediate (no VC)
- Team: Just Andre + designer + ops person

## 7. The Productization Framework

**What Worked:**

**Step 1: Solve for Yourself**
- Andre: "Build tool I wish existed"
- Had done the service, knew pain points
- Built exactly what customers needed

**Step 2: Do Service Version First**
- Validate before building
- Test with 5-6 customers
- Prove people will pay
- De-risk the build

**Step 3: Design Before Code**
- Spend 5 weeks in Figma
- Get customer feedback on direction
- Don't build wrong thing
- Figma feedback > built feedback

**Step 4: MVP Only**
- Don't try to be Klaviyo
- Do one thing well
- Ship in 2 weeks
- Gather real usage data

**Step 5: Move Fast on Feedback**
- Weekly updates based on customer requests
- Show responsiveness
- Build community feeling
- Early customers become advocates

## 9. Key Operational Decisions

**Decision 1: No VC**
- Profitable from day 1
- Keep full control
- No pressure for growth at all costs

**Decision 2: Keep It Simple**
- 2-tier pricing (not 5)
- Core features (not everything Klaviyo does)
- One main use case (Shopify + email list)

**Decision 3: Hire Right**
- Started with 3 people: Andre (founder), designer, ops
- Designer handles design updates
- Ops handles customer support
- Andre focused on strategy + product

**Decision 4: Distribution (Shopify App Store)**
- Built Shopify app version
- Listed in app store (free marketing)
- App store handles payment processing
- Shopify handles discovery

## 11. Lessons from 87-Day Win

**Lesson 1: Productize Services First**
- Do service version
- Validate with paying customers
- Then build software
- Reduces risk 10x

**Lesson 2: Mockups Before Code**
- Figma feedback > developer feedback
- 10x cheaper
- 100x faster
- Shows real validation

**Lesson 3: Simplicity Wins**
- Don't copy Klaviyo features
- Do one thing well
- Better than jack-of-all-trades
- Easier to understand

**Lesson 4: Speed**
- 9 weeks to $2.4M ARR
- Not because magic
- Because focus + existing audience + simple product

**Lesson 5: Audience Matters**
- Andre's 10K email list = unfair advantage
- Not saying impossible without
- But easier with warm audience
- Could still work cold but slower
