## 3. Product & MVP Strategy

- Output: List of class action lawsuits user qualifies for
- Feature: Generate PDF form ready to mail in
- Monetization: Premium subscription to see more lawsuits

**Building Approach:**
- 2-week build using 100% AI (Claude)
- Focused on core features (not perfect)
- Heavy emphasis on onboarding (UI/UX)
- Created data structures in advance (told AI what data looks like)

**Onboarding Philosophy:**
- "90% users only see onboarding if paywall"
- "Spend as much time on onboarding as core features"
- 4 key onboarding components:
  1. Invoke emotion (make user feel strongly)
  2. Show strongest incentives (how life improves)
  3. Personalization (feels meant for them)
  4. Social proof (charts, graphs, scientific validation)

## 11. Strategic Insights

**App Building Playbook (Connor's 5-Step System):**

**Step 1: Download & Study Competitors**
- Download 20 apps in target niche
- Screenshot every page
- Organize in Figma
- Pick best designs

**Step 2: Design Data Structures**
- Create text doc describing data shapes
- Include JSON examples
- Feed to AI for reference
- Enables AI to code faster

**Step 3: Build Core Features**
- Skip onboarding initially
- Go straight to main functionality
- Use Claude to write code from screenshots
- Accept imperfection

**Step 4: Onboarding (Last)**
- Spend equal time on onboarding
- 4 key components: emotion, incentives, personalization, proof
- Goal: Convert user before paywall

**Step 5: Validation & Iteration**
- Launch MVP
- Test with creators
- Iterate based on feedback

**Core Philosophy:**
- "Don't seek waitlist feedback; build first"
- "Any app can make thousands/month"
- "Your idea doesn't have to change society"
- "Onboarding pulls weight for conversions"

## 15. Lessons & Insights for First-Time Builders

**Green Flags (What Works):**
- Build utility apps (not social) for solo builders
- Spend 50% time on onboarding (conversion driver)
- Copy best designs from competitors (iterate, don't innovate)
- Use AI coding (100% with Claude)
- Test core functionality first (onboarding last)
- UGC creator partnerships (cheaper than paid ads)
- Validate with creators before scaling paid
- Accept imperfection (launch MVP quickly)
- Clear value proposition (help find money = easy sell)

**Red Flags (What Doesn't Work):**
- Social apps (hard for solo builders)
- Perfect MVP (delays launch)
- Generic apps (need specific value)
- No onboarding focus (low conversion)

**Actionable Frameworks:**
1. **Validation:** Look at TikTok/Instagram for market proof (people talking about problem)
2. **Building:** 2-week MVP using AI (Claude + Cursor)
3. **Design:** Download 20 competitors, screenshot, organize, iterate
4. **Data:** Create JSON structure doc for AI reference
5. **Onboarding:** 4 components (emotion, incentives, personalization, proof)
6. **Monetization:** Freemium + subscription paywall
7. **Distribution:** UGC influencers (test organic first)
8. **Scaling:** Paid ads (balance entertainment + conversion)

**Advice to Young Connor:**
- "Build simple with great onboarding"
- "Utility > social (solo builder advantage)"
- "Copy competitors + iterate"
- "Don't overthink; just build"
- "Most failures teach valuable lessons"
- "Your idea doesn't need to be revolutionary"
