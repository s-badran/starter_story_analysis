## 3. Product & MVP

**Build Approach:**
- Discovered Cursor in August 2024
- Realizedcould build enterprise-level software solo with AI
- Built with Cursor exclusively (no traditional coding)

**MVP Process:**
- Day 1: Working prototype
- Weeks 1-7: Continuous iteration with community feedback
- Features: Tweet collection, AI analysis, coaching, content recommendations

**Key Building Insight:**
- Break every feature into micro-steps for AI
- Example: Instead of "build AI brain dump feature" → break into:
  1. Build input form
  2. Build button
  3. Add API call to AI model
- Smaller steps = fewer bugs, faster development

**Tech Stack:**
- Started: Cursor
- Switched: Windsurf (Oct 2024, Cursor "IQ went down")
- Frontend: Next.js
- Backend: Supabase
- Deployment: Vercel
- AI APIs: ChatGPT, Claude, others
- Email: Resend
- Data: X API ($5,000/month!)

## 14. Frameworks

**Cursor Development Framework:**
1. Break every feature into smallest possible steps
2. Ask AI to break down complex requests
3. Use ChatGPT + Cursor in tandem
4. Be specific about scope (prevent AI drift)
5. Iterate fast (move to next step immediately)
6. Accept that building with AI is different than traditional code

**Launch Framework:**
1. Build in public (get feedback)
2. Beta test extensively (150 testers)
3. Create scarcity (announce date in advance)
4. Leverage existing audience
5. Build hype gradually
6. Execute flawlessly (all hands on deck)
