# Story Index: Dmitro Rudyj - Screenshot1 ($12K/month SaaS)

**Founder:** Dmitro Rudyj (Ukrainian developer)
**Company:** Screenshot1 (Screenshot API service)
**Revenue:** $12K/month ($144K+ ARR)
**Model:** B2B SaaS API + Managed Service
**Background:** Developer building tools for developers
**Strategy:** Developer-first positioning, solving own pain point, API monetization

---

## 1. The Origin - Scratching Own Itch

**The Problem:**
- Dmitro needed to convert URLs to screenshots
- Converting websites to images
- No good API existed
- Solutions were expensive ($500+/month)

**The Realization:**
- "I need this tool"
- "If I need it, others probably need it too"
- "Why not build and sell it?"

**Timeline:**
- Started as side project while employed
- Built in spare time
- Initial customers: Friends + referrals
- Eventually: Full-time business

---

## 2. Screenshot1 - What It Does

**The Service (Core Value Prop):**
- Converts any URL into screenshot/image
- Done via API
- Handles JavaScript rendering
- Returns image in multiple formats

**Real-World Use Cases:**
- Website previews (showing what site looks like)
- Social media link previews
- Documentation screenshots
- Automated testing
- Web scraping with images
- Email previews

**Why It's Needed:**
- Chrome/browsers can screenshot, but:
  - Requires running browsers (expensive)
  - Requires infrastructure
  - Requires scaling
  - Requires maintenance
- Screenshot1: All handled, just API call

---

## 3. The Product Philosophy

**Simplicity Over Features:**
- Single job: Convert URL → Screenshot
- Does one thing very well
- Not: Website builder, image editor, design tool
- Focus: Reliability, speed, simplicity

**Developer Experience:**
- API first (not web UI)
- Documentation exemplary
- Pricing simple ($25-$100/month tiers)
- Free tier for experimentation

**The Bet:**
- Better API > prettier dashboard
- Developers value simplicity
- Developer-first companies win

## 10. Build vs. Buy Economics

**Why Companies Use Screenshot1 (vs Building In-House):**

**Build In-House Cost Analysis:**

Infrastructure:
- Servers: $1,000-2,000/month minimum
- Maintenance: One engineer minimum
- Scaling: DevOps expertise required
- Uptime responsibility
- Total: $8,000-15,000/month + opportunity cost

**Buy Screenshot1 Cost Analysis:**
- API usage: $25-100/month
- Integration time: 2-4 hours one-time
- Total: $300-1,200/year

**Economics:**
- Build in-house: $100K+/year
- Buy API: $1,200/year
- Leverage: 100:1 in favor of buy

**This is why SaaS APIs are powerful:**
- High leverage
- One engineer builds once
- Sells to 1,000+ companies
- Each saves 100 engineers

## 11. The Sustainability Model

**What Could Threaten Screenshot1:**

**Threat 1: Large Player Entry**
- Google, AWS, Azure enter market
- Could offer cheaper
- But: Dmitro has head start, customer relationships
- Market large enough for multiple

**Threat 2: Open Source**
- Playwright, Puppeteer free alternatives
- Eliminates some TAM
- But: Still easier to use managed service
- Like Linux vs AWS (both coexist)

**Threat 3: Feature Creep**
- Temptation to add everything
- Better: Stay focused on core value
- Dmitro staying focused

**What Protects Screenshot1:**

1. **Reliability Moat**
   - Customers depend on API
   - Switching cost = integration effort
   - Once integrated, sticky

2. **Network Effects**
   - More customers = more revenue
   - More revenue = better infrastructure
   - Better infrastructure = more reliable
   - Competitors can't catch up easily

3. **Focus**
   - Does one thing well
   - Generalist competitors lose focus
   - Specialist wins

## 12. Lessons on Focus & Simplicity

**Principle 1: Simple > Complex**
- Screenshot1 does ONE thing
- Does it exceptionally well
- Temptation to add: "Also export to PDF", "Also host images", "Also design tools"
- Reality: Each addition dilutes focus

**Principle 2: API First > UI First**
- Developers want API
- UI nice-to-have
- Screenshot1 prioritizes API
- Result: Developer love

**Principle 3: Reliability > Features**
- Feature rich = interesting
- Reliable = valuable
- Screenshot1: "You can depend on this"
- Worth premium over unreliable competitors
